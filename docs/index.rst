PBNightingale
=============

**PBNightingale** is a graphical GPG/OpenPGP key management utility for
Linux, macOS and Windows. It lets you create and manage encryption keys,
sign other people's keys to build a web of trust, and publish keys to
keyservers — all without touching a command line.

New to GPG? Start with :doc:`manual/concepts` — it explains what a key
pair is and why you would want one, before anything about the application
itself.
